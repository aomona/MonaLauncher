# Linux共通権限の統合検証 — 2026-09-12

## 対象

`SandboxPolicy` とインスタンスの保存済み `gameWrite` / `narrator` を、本体のLinux起動処理へ接続した。検証CLIも同じインストーラー・起動処理・bubblewrap実装を呼ぶ。旧sandbox-labの成功を本体の成功として代用していない。

- UTM VM: `MonaLauncher Linux Desktop`、UUID `2FAE16CE-523F-4904-8B19-0E262E1C3A10`
- Ubuntu 24.04.5 ARM64、4 CPU、6 GiB RAM、Mesa 25.2.8 llvmpipe、X11
- Minecraft 26.2 Vanilla demo、管理下のTemurin Java 25、LWJGL 3.4.1 ARM64の固定済みアーティファクト
- 仮想音声デバイス `intel-hda`、PulseAudioの `Built-in Audio Analog Stereo`
- VMを非表示で操作し、ゲスト内のxdotoolとscrotだけを使用。ホストのマウス・キーボードをキャプチャしていない。

## 検証で修正した問題

修正後、本体のHome画面のPlayからMinecraftを起動し、Javaプロセスが60秒間生存していることと、タイトル画面・ランチャーのRunning表示を同時に確認した。`reports/native-play-60s.png` に記録した。ゲームのQuit Gameで終了し、Javaプロセス消滅とランチャーのPlay表示への復帰も確認した。

- ARM64でx64のLWJGL nativeを選んでいたため、対象の11ファイルを上流ARM64アーティファクトへ置換し、サイズ・SHA-1・許可URLを固定した。
- Linux JREのlegal文書エイリアスを安全な通常ファイルのコピーとして展開するようにした。legal外やツリー外へのリンクは引き続き拒否する。
- `--disable-userns` と併用する `--unshare-user` を明示した。
- 本体の一時的な起動スレッドが終了すると、Linuxのparent-death signalでゲームも終了していた。専用スレッドをプロセス所有期間中維持し、回帰プローブを追加した。
- 6 GiBのVMで3バイナリの同時リンクがOOMになったため、最終ビルドは `-j 1` で実行した。

## 保証しない範囲

- X11とPulseAudioは互換性のためのサービス許可であり、描画・再生だけに限定されない。他のX11クライアント操作や録音等が可能な点をUIと共通ポリシー文書で明示した。
- 音声の観測は出力波形とプロセス状態。ユーザーの聴取確認ではなく、波形からゲーム音・ナレーターを個別に識別していない。
- 実GPU、native Wayland、Linux x86_64実行、任意のMinecraft／Mod、Linux Microsoft資格情報保存、Windows実機は今回の検証外。
- AppArmorプロファイルの配布パッケージへの自動登録は未実装。システム全体の制限は無効化していない。

ローカルのログ・スクリーンショットはGit対象外の `reports/` に保存。再現手順は [README](README.md)、権限の意味は [共通ポリシー](../../docs/sandbox-policy.md) を参照。
